A faster drop-in for csv-reader 1.0.0: `solve.js` answers every `{text, header}` exactly as the reference does — same columns, rows and errors on broken CSV — in a single pass with `charCodeAt`, one slice per field instead of per-character concatenation, and `indexOf` to jump to the next quote. `main.ts` reads `/input/cases.json` and writes `/output/answers.json`.

## Run it

```sh
node main.ts
```
